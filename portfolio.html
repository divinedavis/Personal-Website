hair-markers — A Medical Model That Runs Entirely On My Laptop

Private tool

  • Ask it a health question in the terminal and it answers from my own lab results — it reads the PDFs straight out of my records folder, quotes the actual value and reference range, and picks up a new file the moment I drop one in
  • Every morning it sweeps PubMed, Europe PMC, medRxiv and ClinicalTrials.gov for research touching my specific markers, files anything new into a local corpus, and writes a digest — the honest answer most days is “nothing here changes anything,” which it says plainly instead of manufacturing a finding
  • No API keys, no cloud, no account — the whole thing runs offline, and the only thing that ever leaves the machine is a literature search term, never a lab value
  • Architecture: two open-weight models under Ollama — II-Medical-8B (a Qwen3-8B medical fine-tune, Q5_K_M) for reasoning and Google’s MedGemma 1.5 4B (Q8_0) for reading scans; retrieval is hybrid, fusing SQLite FTS5 BM25 with 768-dim nomic-embed-text vectors through reciprocal rank fusion so a question phrased in plain language still finds the clinically-worded paper; 24k context holds the records, the retrieved abstracts and the conversation at once, and prompt-prefix caching plus suppressed chain-of-thought took a lookup from 75 seconds to under 8 on 16 GB of unified memory
