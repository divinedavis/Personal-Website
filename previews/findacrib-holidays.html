Find A Crib holidays

The same idea as Marracat's holiday theming, fitted to Find A Crib: the opening splash, the skyline strip under the search bar, the Map pill, the tab bar, the app icon and an App Store event change for each holiday, then go back to normal. Pick a day below.

Glass tab barHolidays

1. Opening splash
the day's background and glow, with a line under FIND A CRIB

2. Search results
skyline strip, Map pill glow and the selected tab in the day's colours (on the light glass bar)

3. App icon
the real logo's house on the day's colours, Home Screen only (the App Store keeps the normal icon). On by default, can be turned off in Profile

4. App Store event (owner 10/24: yes)
each one opens a real Find A Crib tool with the holiday as the reason, never just the colours (App Review rejected a cosmetic-style event on 10/20, rule 2.3.13). Days marked "no event" say why

5. App Store assets
the App Store always shows the real logo; only the colours around it change. The product page header (a short looping video, like Marracat's), the search results image, and the event's card and details art, with the real logo large in the middle. The header is swapped onto the live App Store page during the holiday, then back.

How it would work

  • One list of holidays (holidays.json in the app), copied from Marracat's: the dates, how many days around each holiday the look is on, the colours, the splash line and the event wording. When two overlap, the shorter one wins (Thanksgiving beats the Gift Guide).
  • The app reads that list at launch, no new build per holiday. The colours used here are Marracat's own, so the two apps match on the same days.
  • App Store events (owner 10/24): 9 days get one, each opening a real tool: Halloween and Thanksgiving are already with App Review; Veterans Day, Happy Holidays, New Year's, MLK Day, Black History Month, DC Emancipation Day and Juneteenth are proposed here for your OK. Shopping days and days already covered by a renter event get none. Each event goes to review on its own, never with an app update, so a rejection can't hold a release. The holiday header and search image (section 5) can still be swapped onto the live page; the logo in them is always the real one.
  • Tests always see the everyday look, so the holidays never break the UI tests.

Your calls

  • Which days: exactly Marracat's 21, with the same dates, colours and how long each look stays on. Only the App Store event wording is Find A Crib's own (renter-focused: lotteries, rent-stabilized buildings, your rights). The Heat season App Store event that's already running stays as its own event.
  • Icon switching. iOS shows a "You have changed the icon" alert every time it changes. Marracat accepted that with the switch on by default; Find A Crib could do the same or start with it off.
